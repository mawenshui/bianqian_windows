# StickyNote v1.10.0 开发与发布验证

## 实施范围

本版按 [六项优化设计方案](./plans/2026-10-16-p0-p1-optimizations-design.md) 的顺序交付 P0-1、P0-2、P0-3、P1-1、P1-2、P1-3。核心编辑、导入、检索、提醒、备份与恢复仍可离线使用。

| 顺序 | 实现与数据边界 |
| --- | --- |
| P0-1 | 成功落盘后记录有界单张历史；快照自包含附件和背景资源。恢复前强制保留当前版；归档可查看，回收站恢复保留 `note_uuid`，永久删除清理历史。启用主密码时仅历史加密，便签 JSON 与备份不宣称整体加密。 |
| P0-2 | 带格式版本、大小与 SHA256 清单的明文迁移包，导入前做路径、重复项、CRC、关联资源校验；仅向空白库导入，自动空白占位便签可替换，导入前建立安全备份，写入异常回滚。 |
| P0-3 | 快速切换使用现有本地记录缓存和打开便签的实时数据；托盘与可配置快捷键可达，归档项需明确取消归档。 |
| P1-1 | 清单条目加稳定 `item_id`，旧数据首次修改时迁移；聚合视图勾选回写原便签，打开便签复用撤销栈，归档只读。 |
| P1-2 | 沿用拖边、标签、悬停预览和箭头固定展开；仅增加贴边状态落盘、启动恢复及托盘列表/展开全部。普通隐藏仍独立。 |
| P1-3 | 演示遮蔽先原子保存基础可见性快照再隐藏窗口；启动时读取遮蔽状态，手动结束后恢复。提醒继续记录触发但不显示正文通知。该功能不承诺系统级录屏窗口排除。 |

## 与原设计的实施差异

- 历史资源存入各快照，删除原附件后仍可独立恢复；尚未做跨快照的内容寻址去重。单个超 200 MB 的快照暂停记录，正常便签保存继续。
- 迁移包只实现空库完整往返，不提供非空库自动合并；已存在的自定义主题文件若内容冲突会拒绝导入。
- 演示遮蔽为主动隐藏，未调用系统级录屏排除 API。
