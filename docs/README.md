# StickyNote 开发文档索引

## 文档概述

本目录包含 **StickyNote** 桌面便签应用程序的完整开发文档，涵盖项目概述、系统架构、功能需求、模块设计、数据模型、主题系统、UI 交互、开发规范以及后续优化计划。

项目目录职责、测试闭环、语义化版本、双格式打包及 GitHub Release 的强制流程，以根目录的 [项目维护与发布规范](../AGENTS.md) 为准。
