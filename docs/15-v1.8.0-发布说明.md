# StickyNote v1.8.0 发布说明

本说明对应 v1.8.0 的源码、MSI 安装版与便携版。功能设计和数据边界详见 [开发说明](./13-v1.8.0-开发说明.md)。

## 本次更新

- 搜索结果增加命中高亮、上下文摘要和本地组合筛选；支持命名智能视图。
- 新增归档、回收站、恢复、保留期限及相关批量操作。
- 便签支持复选框清单、完成项折叠及未完成项筛选。
- 备份增加 SHA256 校验、恢复预览与安全快照；TXT 导入支持预览、重复项处理和失败报告。
- 新增快速记录、附件列表、图片粘贴与文件拖放；附件参与备份、回收站和恢复。
- 新增提醒中心、错过提醒补处理、列表视图与排序偏好、桌面布局预设。
- 核心记录、整理、提醒、恢复和迁移可离线使用。

## 验证

- Python 编译检查、完整自动化测试 342 项及 69 个子测试通过；`core/` 与 `features/` 总覆盖率 56%。
- 便携 ZIP 包含 EXE、主题、插件和手册；EXE 内嵌版本 1.8.0，启动后保持运行。
- MSI 产品版本 1.8.0，管理解包、静默安装、桌面快捷方式指向、安装后启动及卸载检查通过。
- 已有 PDF 导出用例在 Windows 输出 `0x80040155` 诊断信息，但测试仍通过；PDF 实际文件和物理鼠标交互、托盘通知、文件拖放、DPI/多屏布局仍建议在目标桌面进一步检查。
- 正式资产的 SHA256 见同版本 GitHub Release 的 `SHA256SUMS.txt`。
