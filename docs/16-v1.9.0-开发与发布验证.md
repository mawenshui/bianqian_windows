# StickyNote v1.9.0 开发与发布验证

本版按 [现有功能优化清单](./14-现有功能优化与后续扩展清单.md) 第一节的顺序实施。所有核心操作仍可离线使用。

## 八项实施结果

1. **备份与恢复**：恢复预览按当前文件与备份逐项比较，列出新增、覆盖、内容相同及当前独有便签，并统计附件数量与大小。失败时报告错误步骤和恢复前安全备份路径。
2. **回收站与附件**：永久删除和保留期限清理显示便签、附件和背景图影响；清理前校验完整安全备份。孤立附件先归档到独立 ZIP，校验后删除，其他便签附件不受影响。
3. **搜索与智能视图**：搜索窗口显示全部生效条件、归档范围与结果数；本地记录缓存仅重读变化的 JSON，损坏时自动重建，也可调用索引重建。缓存不写入用户数据目录。
4. **提醒中心**：启动加载后补检；轮询识别时区或休眠后的时间跳变，显示最近检查原因。一次性与周期性提醒保留周期触发记录；稍后提醒和完成可在当前运行中撤销最近 20 次操作。
5. **清单与 Markdown**：清单维护独立的 50 步撤销/重做历史。复制选中和粘贴项目仅在用户点击时访问剪贴板；预览和 TXT/Markdown 导出追加清单状态，不修改富文本正文。
6. **快速记录与批量操作**：托盘区分手动输入和从剪贴板输入；后者仅在点击后读取。批量列表显示选中数量、成功及未处理数量；删除进入回收站。
7. **布局、主题与无障碍**：布局预设记录保存时的屏幕可用区域，恢复时按当前屏幕尺寸映射并限制在可见范围；兼容旧预设。高对比度主题沿用现有 `high_contrast.css`，关键列表、状态与编辑控件提供屏幕阅读器名称。
8. **双格式发布**：以下清单固定检查 MSI、便携版、迁移及数据保留。

## 数据位置与迁移约束

- 源码模式的用户数据在仓库 `runtime/`，不得提交。
- 冻结后的 EXE 将数据放在 EXE 所在目录。MSI 安装版和便携版都遵循这一规则；卸载与移动前应先备份 `notes/`、`trash/`、`backups/`、配置及附件。
- 跨位置迁移应复制完整安装/便携目录，不能只复制 `note_*.json`，以免遗漏附件和配置。
- 现场没有多屏、屏幕阅读器或已有 1.8.0 安装时，对应验证必须如实标记未覆盖，不能推断通过。

- 便携 ZIP 已核对 EXE、主题、高对比度主题、插件与手册；EXE 产品版本 1.9.0，解压启动后进程持续运行。复制完整目录到新位置，测试便签和设置均在新位置，仍可启动。
- MSI ProductVersion 为 1.9.0，管理解包、静默安装、桌面快捷方式目标、启动和卸载通过。卸载移除程序与快捷方式，测试用户数据保留。

- 本机未具备物理多屏和屏幕阅读器环境；这两项仅完成代码边界检查与发布清单记录，待目标桌面复核。Windows 离屏 PDF 测试仍输出既有 `0x80040155` 诊断，但用例通过。
