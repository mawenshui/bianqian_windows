# StickyNote v1.7.9 发布说明

本说明对应 v1.7.9 的源码、MSI 安装版与便携版。

## 本次更新

- 贴边隐藏的便签在标签标题或空白区域悬停 300ms 后临时预览，鼠标离开便签后自动收回原来的屏幕边缘。
- 标签箭头区域悬停不会触发预览；左键点击箭头或使用 Enter/Space 可保持展开。
- 新版悬浮预览默认开启，可在设置 → 主题 → 贴边便签交互中关闭并立即恢复旧版整条标签页的悬停与点击行为；偏好会保存。
- 临时预览时便签内显示模式提示，边缘保留可点击箭头；鼠标停留在箭头上时不会自动收回。
- 修复预览动画结束时提前清除隐藏位置，导致自动收回失效的问题。
- 临时预览不主动抢夺键盘焦点。
- 修复 MSI 桌面快捷方式可能指向错误安装路径的问题。

## 当前验证

- Python 编译检查通过。
- 贴边隐藏、设置和配置相关测试：70 项及 17 个子测试通过。
- 完整测试：317 项及 65 个子测试通过；编译检查通过。
- 覆盖率检查通过，`core/` 与 `features/` 总覆盖率 52%。
- Windows Qt 平台相关测试：46 项及 17 个子测试通过；正式便携版可执行文件启动后保持运行。
- MSI 已完成管理解包、静默安装、桌面快捷方式指向及启动、卸载检查；两份正式资产的 SHA256 已复核。
- Windows 物理鼠标操作需由用户进一步手动体验。
