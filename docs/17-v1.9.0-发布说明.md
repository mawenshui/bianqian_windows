# StickyNote v1.9.0 发布说明

本版完成 [现有功能优化清单](./14-现有功能优化与后续扩展清单.md) 的八项改进。实现规则及 MSI/便携版检查项见 [开发与发布验证](./16-v1.9.0-开发与发布验证.md)。

## 更新内容

- 备份恢复显示差异与附件占用；失败时给出安全快照位置。
- 回收站清理先预览影响并做安全备份；孤立附件先归档再清理。
- 搜索显示生效条件和结果范围，以本地增量缓存减少重复读取。
- 提醒中心显示补检与重复周期状态，可撤销稍后提醒或完成。
- 清单支持撤销/重做、复制粘贴及带勾选状态的 Markdown/TXT 导出。
- 批量操作显示选中数与结果，托盘快速记录明确剪贴板入口。
- 布局预设适配屏幕尺寸变化，完善高对比度与无障碍检查清单。

## 验证

- Python 编译检查通过；完整自动化测试 351 项、69 个子测试通过；`core/` 与 `features/` 合计覆盖率 56%。
- 便携版内容、EXE 版本、启动与目录迁移通过；MSI 产品版本、管理解包、静默安装、快捷方式、启动和卸载通过。受控 v1.8.0 → v1.9.0 升级保留了测试便签，卸载保留测试数据。
- 正式资产 SHA256 见同版本 Release 的 `SHA256SUMS.txt`。Windows 离屏 PDF 测试会输出既有的 `0x80040155` 诊断，但用例和完整测试集均通过；物理多屏及屏幕阅读器仍需在具备条件的设备上复核。
