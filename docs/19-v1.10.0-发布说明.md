# StickyNote v1.10.0 发布说明

v1.10.0 按 [六项优化设计方案](./plans/2026-10-16-p0-p1-optimizations-design.md) 增加单张便签历史、可往返的离线迁移包、键盘快速切换、清单总览、贴边状态持久化与演示遮蔽。

- 历史记录包含当时引用的附件和背景图，恢复前保留当前内容；启用主密码时历史独立加密。现有便签 JSON、迁移 ZIP 和整库备份仍为明文。
- 迁移包带 SHA256 清单与导入预览，只导入空白库，并在修改前创建安全备份。
- 快速切换、清单总览和贴边列表从托盘进入，贴边仍保持原有悬停预览与固定展开交互。
- 演示遮蔽在异常重启后继续保持，直到用户从托盘结束；它是主动隐藏，不是系统级录屏排除。

完整测试 371 项及 69 个子测试通过；便携版启动、MSI 管理解包与静默安装、快捷方式及卸载已验证。测试与安装产物记录见 [开发与发布验证](./18-v1.10.0-开发与发布验证.md)。
