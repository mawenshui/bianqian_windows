# StickyNote v1.10.1 发布与验证

发布日期：2026-10-19。v1.10.1 是 v1.10.0 的兼容性修复版本；新增的测试与修复细节见 [后续回归测试记录](./20-v1.10.0-后续回归测试记录.md)。核心功能继续离线可用。

## 用户可见修复

- 保存失败时，备份、恢复、归档、移入回收站、演示遮蔽及退出会停止相应操作并保留当前数据；自动备份会跳过失败轮次。
- 备份、迁移包、历史快照对损坏清单、缺失资源和不安全路径做更严格校验；恢复失败时回滚，历史损坏快照不会阻断可用版本。
- 模板和标签采用原子写入，失败时保留旧文件和内存状态；关闭自动格式化后恢复富文本粘贴。
- 本地和 WebDAV 同步将下载、上传和远端列表错误报告为失败；双版本冲突保留远端副本。缺少删除标记时不会传播单方文件缺失，防止误删。
- 主密码界面澄清保护范围：历史快照可加密，便签 JSON、备份和迁移包仍为明文。

## 自动化验证

- Windows、Python 3.12：`compileall` 通过。
- 版本升级前后分别运行完整 `pytest` 与覆盖率检查，均为 **426 项测试、69 个子测试通过**；升级后 `core` 与 `features` 总体语句覆盖率 **60%**。
- 仅有一条预期警告，来自测试故意构造重复 ZIP 条目的反例；没有失败用例。
- 上一轮还连续重复两次完整测试，结果相同；原生 Windows Qt 富文本剪贴板验证通过。
