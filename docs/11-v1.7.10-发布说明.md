# StickyNote v1.7.10 发布说明

本说明对应 v1.7.10 的源码、MSI 安装版与便携版。

## 本次更新

- 修复多个便签收起在同一屏幕边缘时，标签与展开箭头互相覆盖的问题。
- 标签优先在原便签附近寻找空位；单排空间不足时移到靠内的一排，并保留标签间距。
- 临时预览中的窄箭头会保留完整标签的位置，便签重新收起时不会覆盖其他箭头。
- 按便签收起前的位置识别屏幕，减少多显示器间的错误布局。
- 修复便签初始化期间 Qt 提前投递事件时可能出现的属性访问错误。

## 验证

- Python 编译检查、完整自动化测试 320 项及 69 个子测试通过；`core/` 与 `features/` 覆盖率 52%。
- Windows Qt 平台相关测试 49 项及 21 个子测试通过。
- 正式便携包已核对版本、目录、ZIP 内容及 SHA256，可执行文件启动后保持运行。
- MSI 已通过管理解包、静默安装、桌面快捷方式指向及启动、卸载检查。
- 物理鼠标交互建议在目标 Windows 桌面上进一步手动体验。
