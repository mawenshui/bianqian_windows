**状态：v1.8.0 正式发布。** 本文对应 [功能调研清单](./12-后续可扩展功能调研.md) 的 P0 与 P1，全部新增核心行为使用本地文件和 Windows/Qt 能力。正式资产和验证结果见 [发布说明](./15-v1.8.0-发布说明.md)。

## P0：优先评估

| 顺序 | 交付内容 |
| --- | --- |
| 3.1 搜索 | 标题与正文命中高亮、摘要、空结果；标签、创建/修改时间、提醒、图片/附件、置顶、归档、未完成清单等本地筛选；归档结果可预览并取消归档。 |
| 3.2 归档与回收站 | 归档不删除文件；删除将 JSON、托管背景图和附件移入本地回收站；支持恢复、永久删除、30 天默认保留期限和批量操作。锁定状态随 JSON 保持。 |
| 3.3 清单 | 便签内复选框清单、完成项折叠、未完成项优先及搜索筛选。 |
| 3.4 数据恢复 | 备份预览和 SHA256 清单校验；恢复前安全快照、失败回滚；TXT 导入预览、重复项跳过选择和失败报告。 |

### 3.4 本地历史版本可行性评估

以下为 v1.8.0 当时的规划记录，已由 v1.10.0 实现和 [数据模型设计](./05-数据模型设计.md) 取代：历史快照尚未实现。原建议按便签保存成功后的内容变化创建快照，先采用每便签最多 **20** 个版本、单便签最多 **10 MB**、所有历史最多 **512 MB** 的上限。原文关于“锁定便签继承现有加密保护”的假设不准确：`locked` 只读，现有便签 JSON 并未整体加密；v1.10.0 对启用主密码后的历史快照单独加密。

## P1：体验增强

| 顺序 | 交付内容 |
| --- | --- |
| 3.5 智能视图 | 搜索条件可命名、覆盖调整、删除；托盘和便签列表提供快捷入口。仅保存条件，不复制或移动便签。标签匹配不区分大小写，中文按原字符比较，「无标签」只匹配空列表；颜色按主题文件名精确匹配。 |
| 3.6 快速捕捉 | 托盘快速记录、用户点击时才读取的剪贴板记录、正文选中文字新建；列表多选支持标签、主题颜色、置顶、归档和导出。 |
| 3.7 附件图片 | 本地附件列表可添加、预览图片、打开、移除；文件拖入正文及粘贴图片成为本地附件。背景图与附件一起纳入备份、回收站、恢复；JSON 批量导出会复制附件。 |
| 3.8 提醒中心 | 未触发、已到期、已完成三种视图；稍后提醒和完成；启动加载便签后检查错过的到期提醒。一次性提醒触发后不会隔天重复触发。 |
| 3.9 界面 | 已有卡片与紧凑列表，新增视图与排序偏好保存、明确的列表焦点和辅助技术名称；启用 Qt 高 DPI 缩放；现有高对比度主题可选。桌面布局可命名保存并按当前屏幕可用区域恢复。 |

### 数据与边界规则

- 智能视图、清单、提醒、附件、布局均不要求账号或联网。可选同步和在线更新功能不影响这些操作。
- 回收站恢复遇到 ID 冲突会分配新 ID，附件相对路径同步更新。保留期限为 0 表示仅手动删除。永久删除无法从回收站撤销，但可通过此前备份恢复。
- 附件限制单文件 50 MB，仅允许数据目录内经过验证的相对路径。外部 URL 仍是普通链接，不作为附件可用性的条件。TXT/Markdown 导出是文本格式，不包含附件；使用列表 JSON 批量导出或完整备份保留附件。
- 提醒按系统本地墙上时间解释；每天/每周/每月以本地日历计算，月末取当月最后一天。夏令时不存在的时间在系统时间越过后补触发，重复的墙上时间以本次日历发生日期去重；系统关机期间错过的当前周期提醒在下次启动后检查。归档或删除便签不参与活动提醒调度。
- 本地 OCR 仅完成可行性评估，未加入本版：需比较中文与英文识别率、安装包大小、CPU/内存占用，并明确扫描范围与隐私提示。无 OCR 时图片附件仍可离线预览和打开。
- 布局只恢复当前打开便签，找不到的便签会跳过；屏幕配置变化后坐标会被限制在当前可用区域内。

## 验证与发布状态

- Windows Python 3.12 / PyQt5 离屏环境：`compileall` 通过；`pytest tests -q` 为 **342 passed、69 subtests passed**；`pytest tests --cov=core --cov=features --cov-report=term-missing -q` 同样通过，总覆盖率 **56%**。
- Windows 原生 Qt 平台短时窗口冒烟通过：便签显示，格式页的清单与附件入口可见，默认操作页不溢出。托盘通知、文件拖放、DPI 与多屏布局仍需人工实机验收。测试期间已有 PDF 导出用例触发 Windows `0x80040155` 诊断信息，但测试进程退出码为 0，PDF 路径宜在实机再次检查。
- 便携 ZIP 的 EXE 内嵌版本为 1.8.0，包含主题、插件和手册，启动后保持运行且未发现致命日志。MSI 的产品版本为 1.8.0，已通过管理解包、静默安装、快捷方式指向、启动和卸载检查。
