# StickyNote v1.10.2 发布与验证

发布日期：2026-10-19。v1.10.2 是 v1.10.1 的兼容性界面修复版本，沿用离线优先的数据和安装方式。

## 修复范围

- `ChecklistWidget` 根据便签语义色绘制清单列表、输入框、按钮、勾选及交互状态；主题切换或背景图片变化时同步刷新，不改动清单数据。
- 临时预览便签激活或被抬高后，独立的侧边箭头保持在便签上方；预览结束后不再抬高箭头。
- 空白处原地单击不再触发拖拽结束的贴边检测；实际拖动仍保留原有吸附和贴边逻辑。

## 测试

- Windows、Python 3.12：`compileall` 通过；清单主题与贴边预览相关测试 31 项及 4 个子测试通过。
- 完整测试 433 项及 69 个子测试通过；`core` 与 `features` 总体语句覆盖率为 60%。一条预期警告来自故意构造重复 ZIP 条目的反例。
- Windows 原生界面检查了浅色和深色主题清单，以及预览箭头的窗口层级；模拟便签重新置顶时，修复前箭头会被遮挡，修复后仍位于便签上方。
