
## 本轮验证和修复

| 功能 | 验证重点 | 修复结果 |
| --- | --- | --- |
| 便签保存及退出 | 写入失败、历史恢复、归档、回收站、退出前保存 | 保存结果向调用者传递；关键操作在保存失败时停止，避免丢失未保存内容 |
| 备份与恢复 | 损坏清单、路径校验、加密历史、同步冲突副本、恢复中断 | 拒绝无效备份；恢复失败回滚；备份前保存所有打开的便签 |
| 跨设备迁移包 | 损坏清单、重复条目、不安全文件名、缺失主题、启动空便签 | 预览先校验；导入失败回滚；仅明确标记的自动占位便签允许替换 |
| 版本历史 | 损坏快照、重置后的缓存、加密历史 | 跳过损坏快照，并确保重置后旧缓存不再暴露历史 |
| 模板与标签 | 重名、损坏 JSON、写入失败 | 原子保存；失败时保留旧文件和内存状态 |
| 本地与 WebDAV 同步 | 远端不可用、哈希比较、上传下载失败、双版本冲突 | 失败不再伪报成功；下载临时文件原子替换；冲突副本保留远端内容。缺少删除标记时不传播删除，避免单方文件消失造成数据丢失 |
| 编辑与导入导出 | 内容识别、富文本粘贴、TXT 重复导入、批量 Markdown ZIP | 关闭自动格式化或剪贴板无文本时，按 Qt 原生方式粘贴 |
| 性能工具 | 缓存统计、异步写入失败 | 修复缓存统计死锁，并清理失败写入的临时文件 |
| 安全提示 | 主密码保护范围 | 界面文案说明历史快照加密；便签 JSON、备份及迁移包仍为明文 |

## 尚未证明的范围

自动化测试无法证明“使用中绝无问题”。当前尤其需要继续提高 `core/manager.py`（24%）、`features/backup.py`（44%）、`features/sync/webdav_client.py`（50%）以及插件加载器（36%）的覆盖率。WebDAV 尚未连接真实服务器进行端到端验证；系统托盘、全局快捷键和多显示器配置也需要进一步实机验证。本记录当时没有生成安装包；后续的 MSI 和便携版验证见 v1.10.1 文档。
